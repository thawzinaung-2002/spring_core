
	Junit Test
	- BeforeAll - must be static, call before of all test annotation methods
	- AfterAll	- must be static, call after of all test annotation methods
	- BeforeEach - call before once per test annotation method call
	- AfterEach - call after once per test annotation method call
	- Test - test method
	
	JdbcTemplate (use ? for parameter)
	- select * from product p where p.id = ?; [with Array]
	
	NamedParameterJdbcTemplate (use name for parameter)
	- select * from product p where p.id = :id;[with Map]
