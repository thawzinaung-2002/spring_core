==========	Maven Dependency Scopes	==========
-	Compile		->	can see in workspace, compile to jar file
- 	Provided	->	can see in workspace, not compile to jar file
-	Runtime		->	cannot see in workspace,compile to jar file
-	Test		->	only test

-	Annotation Based

=========================================================================================


==========	Bean Processors	==========

- Bean Factory Post Processor	:	to change or modify bean definition
- Bean Post Processor			:	customize bean before or after bean creation


=========================================================================================

==========	Event Publisher - Subscriber	==========

- Aware	(ApplicationEventPublisher)	:	to notify of the ApplicationEventPublisher, use to publish event
- EventListener						:	catch the event 


=========================================================================================

==========	Beans Creation	==========

-	Constructor			:	return object of own class
-	Static Factory		:	return object from static method , factory class + factory method
-	Instance Factory	:	return object from instance method , factory bean + factory method
